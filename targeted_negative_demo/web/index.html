Targeted Negative Data

Failure demonstrations that label themselves.
We take a task the robot solves cleanly, then desync the planner's belief from the true scene by one controlled amount — move an object, move the goal, or place an obstacle the planner can't see. Because we know exactly what we changed, the resulting failure is causally labelled by construction: no human annotation, no guesswork about why it failed. The same generic perturbation code runs on every task below — nothing is hand-tuned per task.
